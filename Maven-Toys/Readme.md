# Maven Toys Monthly Sales Dashboard

## Project Description
Maven Toys, a small toy store chain in the US, will receive a new monthly dashboard designed specifically for its Regional Sales Managers. This dashboard provides interactive insights into sales performance, allowing managers to filter data by region, monitor monthly revenue trends, and evaluate year-over-year performance. It also enables comparisons across stores and highlights top-performing and underperforming products, helping managers make data-driven decisions to boost sales.

## Questions from Stakeholders
The following key questions were posed by stakeholders to guide the development of this dashboard:
1. **Can the dashboard allow filtering by region?**
2. **How can we track monthly revenue trends?**
3. **Is it possible to view year-over-year performance within the same dashboard?**
4. **Can we compare performance across different stores?**
5. **How can we identify the products that contributed the most to gains and those responsible for losses?**

These questions emphasize the need for a comprehensive view of sales performance across multiple dimensions and timeframes.
